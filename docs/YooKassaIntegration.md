# Интеграция с ЮKassa

## Описание

Проект интегрирован с платежной системой ЮKassa для обработки платежей за менторские сессии. Интеграция заменяет старую форму ввода данных карты на безопасную оплату через ЮKassa.

## Настройка

### 1. Создание тестового магазина

1. Зарегистрируйтесь в [ЮKassa](https://yookassa.ru/)
2. Создайте тестовый магазин
3. Получите идентификатор магазина и секретный ключ

### 2. Настройка переменных окружения

Создайте файл `.env.local` в корне проекта:

```env
# ЮKassa Configuration
YOOKASSA_SHOP_ID=ваш_идентификатор_магазина
YOOKASSA_SECRET_KEY=ваш_секретный_ключ

# Base URL for return URLs
NEXT_PUBLIC_BASE_URL=http://localhost:3000
```

### 3. Тестовые карты

Для тестирования используйте следующие карты:

-   **5555555555554444** - любая дата в будущем, любой CVC
-   **4111111111111111** - любая дата в будущем, любой CVC

## Архитектура

### API Endpoints

1. **POST /api/payment/create-yookassa** - создание платежа
2. **GET /api/payment/status** - проверка статуса платежа
3. **POST /api/payment/create-sbp** - создание СБП платежа (оставлен без изменений)

### Компоненты

1. **YooKassaPayment** - компонент для оплаты картой через ЮKassa
2. **SbpPayment** - компонент для оплаты через СБП (без изменений)
3. **PaymentSuccessPage** - страница успешной оплаты

## Процесс оплаты

### Карточная оплата

1. Пользователь выбирает способ оплаты "Банковская карта"
2. Нажимает кнопку "Оплатить"
3. Создается платеж в ЮKassa
4. Пользователь перенаправляется на страницу оплаты ЮKassa
5. После оплаты пользователь возвращается на `/payment/success`
6. Система проверяет статус платежа и показывает результат

### СБП оплата

Процесс остается без изменений - через QR-код.

## Безопасность

-   Все платежные данные обрабатываются на стороне ЮKassa
-   Данные карт не передаются через наш сервер
-   Используется SSL-шифрование
-   Каждый платеж имеет уникальный ключ идемпотентности

## Обработка ошибок

-   Валидация входных данных
-   Обработка ошибок API ЮKassa
-   Логирование ошибок для отладки
-   Пользовательские сообщения об ошибках

## Тестирование

1. Запустите проект: `npm run dev`
2. Перейдите к менторам и попробуйте забронировать сессию
3. Выберите способ оплаты "Банковская карта"
4. Используйте тестовую карту для оплаты
5. Проверьте, что платеж обрабатывается корректно

## Продакшн

Для продакшн среды:

1. Замените тестовые ключи на боевые
2. Обновите `NEXT_PUBLIC_BASE_URL` на ваш домен
3. Настройте webhook'и для получения уведомлений о платежах
4. Добавьте дополнительную валидацию и логирование
